## 新手阅读顺序

1. 先订阅：[ChatGPT iOS 订阅](../chatgpt/subscribe-ios.md) 或 [官网自助订阅](../chatgpt/subscribe-official.md)。
2. 再开通登录：[二次验证机制](./subscription-and-access.md)（付款前就该了解手机号绑定的坑）。
3. 装好客户端：[Windows 安装](./windows-install.md)。
4. 按需选模型：[模型选择](./model-selection.md)，用鹈鹕测试确认没被[降智](./troubleshooting.md)。
5. 用量大了再算账：[周额度与中转性价比](./usage-and-limits.md)。
