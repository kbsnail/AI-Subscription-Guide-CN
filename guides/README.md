1. 第一次订阅：先读 [账号安全与付款前检查](./account-security.md)，再按设备选择产品页的订阅教程。
2. 付款卡住：先看产品页的排查文章，再回到这里找对应支付方式的细节。
3. 所有教程都标注了原始记录日期；标有「当前可用性尚未重新验证」的内容，操作前以官方页面为准。
