# ChatGPT Free、Go、Plus、Pro 怎么选？2026 年套餐价格与区别

> 适用：准备订阅或升级 ChatGPT，想搞清楚各档位价格、额度和适用人群的用户。
> 价格信息核对自来源 A（2026-11-12 更新）与公开官方资料；最后核对日期 2026-11-15。套餐与额度随时可能调整，以 [OpenAI 官方定价页](https://chatgpt.com/pricing/) 和账号内显示为准。

以下是官网口径（美元、按月），人民币按当时汇率浮动（来源 A 整理）：

| Free | $0 | 轻度、偶尔问问题 | 10 月 8 日起普通对话用 GPT-6 Luna，日常文字对话不限次；文件、图片等工具有额度；部分地区带广告 |

| Pro 100 | $100 / 月 | 高频使用 Work / Codex 的个人用户 | Work / Codex 用量约为 Plus 的 10 倍，没有五小时限制，适合经常遇到用量限制的人 |

> 价格与档位结构已于 2026-11-16 对照 [OpenAI 官方 Codex 定价页](https://learn.chatgpt.com/docs/pricing)核实：Free $0、Go $8、Plus $20、Pro 三档 $100 / $200 / $500，Pro 无五小时限制，Ultrafast 仅 Pro $500。**表中「约 10 / 20 / 50 倍」是 Codex 负责人 Tibo 在 X 上的说明（见下方时间线），不是官方定价页公布的固定承诺**；官方对用量的口径是「取决于模型、任务大小与复杂度」，以账号内用量面板为准。

### Pro 三档的由来（2026 年时间线）

- Pro 三档是 **9 月 29 日 OpenAI DevDay** 当天改的，倍数出自 [Codex 负责人 Tibo](https://x.com/thsottiaux/status/2104951965184925941) 和 [OpenAI](https://x.com/OpenAI/status/2104993967985381673) 在 X 上的说明，[Pro 200 同一天重新开放](https://x.com/OpenAI/status/2104993969486930015)。
- 美国时间 **10 月 29 日**，Pro 三档的 Work / Codex 额度翻倍（[OpenAI 帮助中心](https://help.openai.com/en/articles/9793128-about-chatgpt-pro-plans)），倍数随之变成约 10、20、50 倍，这是 Tibo 的说法（[原帖](https://x.com/thsottiaux/status/2115850175868727621)，50 倍他[亲自确认](https://x.com/thsottiaux/status/2115851811576053881)）。
- Chat 里 GPT-6 Pro 的每周额度，Pro 100 和 Pro 500 不变，Plus 也不变。

> 旧教程里的「Pro 5× / Pro 20×」是 10 月 29 日翻倍前的叫法，现在对应约 10 倍 / 20 倍。

## 几个容易被忽略的点

- **iOS 内购的 Plus 标价是 $19.99/月**（网页端官网是 $20/月），来源 A 10 月 22 日复核未变。美区 Apple ID 的账单州设为 Oregon 不加销售税，$20 礼品卡刚好够付。iOS 订阅只能在 Apple ID 里管理，网页端管不了。
- **先分清 Chat、Work / Codex 和 API：** Work 与 Codex 共用用量，API 另行计费。模型入口与额度按当前账号显示判断，具体可查 [OpenAI 模型说明](https://learn.chatgpt.com/docs/models) 及 [计划与用量](https://learn.chatgpt.com/docs/pricing)。
- **付费会员不等于无限使用。** Plus 可作为个人订阅的起点；经常达到限额，再比较 Pro 是否满足需求。付费会员也可能有用量限制，不代表所有模型和工具都无限使用（来源 L）。
- **Plus 和 API 不是一回事。** Plus 是 ChatGPT 会员，API 是开发者按使用量单独付费。购买 Plus 不会自动获得 API 余额（来源 D、L，[官方账单说明](https://help.openai.com/en/articles/9039756-managing-billing-for-chatgpt-and-the-api-platform)）。

## 要不要上 Pro？

来源 A 的判断方法：先记录一周内触及用量上限的频率，以及是否影响工作；目前的额度够用时，可以继续使用现有套餐。

- 日常写作、学习和编程：先选 Plus。
- Work / Codex 经常因用量耗尽中断工作：考虑 Pro 100。
- Pro 100 也常用完的重度用户：再看 Pro 200。
- 用 Codex 写代码的重度用户，还可以参考 [Codex 周额度与中转性价比分析](../codex/usage-and-limits.md) 估算自己需要几倍额度。

## 免费版够不够用？

偶尔问答、翻译或写短文，可以先用免费版。经常处理文件、图片、复杂任务，或频繁碰到用量限制，再考虑 Plus。Plus 提供更广的模型与工具访问和更高限额，具体以账号显示为准（来源 L，[官方 Plus 说明](https://help.openai.com/en/articles/6950777-what-is-chatgpt-plus)）。
